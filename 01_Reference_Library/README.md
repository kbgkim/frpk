# 01 — Reference Library

## Purpose
Curated collection of external reference materials — papers, regulatory documents, industry standards, textbooks, and authoritative sources used as input or citation for the FRKP.

## Scope
- PDFs, links, and summaries of external references
- Annotated bibliographies
- Regulatory frameworks (Basel, IFRS, ISO, etc.)
- Academic papers and industry whitepapers
