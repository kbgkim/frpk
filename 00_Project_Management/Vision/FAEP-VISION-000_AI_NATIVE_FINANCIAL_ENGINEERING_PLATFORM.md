# Philosophy

FAEP는 AI를 사용하는 플랫폼이 아니다.

FAEP는 AI가 금융 플랫폼을 구축하도록 지원하는 Operating System이다.

AI는 사용자(User)가 아니라 Platform Worker이다.

사람은 Governance를 담당한다.

AI는 Execution을 담당한다.

---

# Core Principle

Everything becomes a Contract.

Everything executable becomes a Workflow.

Everything repeatable becomes an Automation Profile.

Everything automatable becomes an Agent.

Everything validated becomes a Core Capability.

# Provider Independence

FAEP never standardizes AI products.

FAEP standardizes Capabilities.

Providers are replaceable.

Capabilities are stable.

---

# Runtime Independence

---

# Long-term Goal

A financial institution should be able to execute:

Run IB Bootstrap.

Run Bundle Publishing.

Run Risk Validation.

Run Knowledge Synchronization.

without describing the workflow.

FAEP already knows the workflow.
