# 00 — Project Management

## Purpose
Central hub for all project governance, planning artifacts, and process documentation that guides the development and maintenance of the FRKP.

## Scope
- Project charter, roadmaps, and strategic planning
- Sprint planning, backlog management, and task tracking
- Governance policies, metadata schemas, and document lifecycle rules
- Review checklists, meeting notes, and audit records
- Templates for consistent document creation

## Relationship with other folders
| Folder | Relationship |
|---|---|
| All directories | All content in the repository is governed by the rules defined here. |
| 01_Reference_Library | References are catalogued and versioned per policies in this folder. |
| 02_Knowledge_Base | KB articles follow templates and lifecycle rules defined here. |
| 99_Archive | Completed sprints and superseded plans are moved to Archive. |
