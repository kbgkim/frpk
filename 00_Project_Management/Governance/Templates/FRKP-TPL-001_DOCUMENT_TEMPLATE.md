# Template Usage

본 템플릿은 다음 문서에 공통 적용한다.

| Prefix | Document Type           |
| ------ | ----------------------- |
| RL     | Reference Library       |
| KB     | Knowledge Base          |
| AN     | Analysis                |
| FC     | Formula Catalog         |
| MF     | Mathematical Foundation |
| IMP    | Implementation Guide    |
| ARCH   | Architecture Guide      |
| BUNDLE | Bundle Review           |
| GOV    | Governance              |

필요하지 않은 Optional Section은 제거할 수 있다.

# Template Design Principles

본 템플릿은 다음 원칙을 따른다.

* CommonMark 기반 작성
* YAML Front Matter 미사용
* 플랫폼 독립성 유지
* 문서 간 구조 일관성 유지
* Cross Reference 중심 설계
* 유지보수 용이성 확보

---

# Summary

본 템플릿은 FRKP 프로젝트의 모든 공식 문서에 공통 적용되는 표준 문서 템플릿이다.

문서의 구조를 표준화하여 일관성, 유지보수성 및 추적성을 확보하며, 모든 Bundle과 Governance 문서는 본 템플릿을 기반으로 작성하는 것을 원칙으로 한다.
