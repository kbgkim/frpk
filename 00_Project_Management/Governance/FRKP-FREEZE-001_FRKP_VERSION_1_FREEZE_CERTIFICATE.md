# 1. Purpose

본 문서는 Financial Risk Knowledge Platform(FRKP) Repository Version 1.0에 대한 공식 Freeze를 선언한다.

Freeze는 Repository 구조, Governance 체계, Knowledge Layer, Bundle 구조 및 핵심 표준을 Version 1.0의 기준선(Baseline)으로 확정하는 것을 의미한다.

본 문서는 향후 FRKP의 모든 변경과 확장이 준수해야 할 기준 문서이다.

---

# 2. Scope of Freeze

Version 1.0 Freeze는 다음 범위를 포함한다.

* Repository Directory Structure
* Governance Standards
* Document Identifier System
* Bundle Methodology
* Layer Architecture
* Knowledge Production Model
* Formula Documentation Standard
* Review Framework
* Knowledge Graph Framework
* Publishing Structure

Version 1.0 이후의 신규 Bundle과 신규 문서는 본 기준을 기반으로 확장한다.

# 8. Freeze Constraints

Freeze 이후 Version 1.0 기준선에 대해 다음 원칙을 적용한다.

허용되는 변경

* 신규 Bundle 추가
* 신규 문서 추가
* 오탈자 수정
* Broken Link 수정
* 명확성 향상
* Revision History 갱신

허용되지 않는 변경

* Layer 구조 변경
* Bundle Methodology 변경
* Governance Standard의 비호환 변경
* Document Identifier 체계 변경
* Repository Top-Level 구조 변경

이와 같은 변경은 차기 Major Version에서만 검토한다.
