## Review Criteria

### Content
- [ ] All claims are accurate and supported by references
- [ ] No factual errors or outdated information
- [ ] Content is complete (no TODO markers or placeholders)
- [ ] Examples and calculations are correct
- [ ] Scope matches the document's stated purpose

### Structure
- [ ] Document follows the appropriate template
- [ ] Table of contents is accurate (if applicable)
- [ ] Sections are logically ordered
- [ ] Heading hierarchy is correct (no skipped levels)

### Cross-References
- [ ] All internal links point to existing documents/anchors
- [ ] All formula references use correct catalog IDs
- [ ] All glossary terms are linked or defined
- [ ] External references are cited correctly

### Formatting
- [ ] Markdown renders correctly (no broken syntax)
- [ ] Tables are properly formatted
- [ ] Code blocks have language annotations
- [ ] Images/diagrams are included and referenced

### Metadata
- [ ] Document ID follows numbering rules
- [ ] Status is correct
- [ ] Version number is appropriate
- [ ] Owner is specified
